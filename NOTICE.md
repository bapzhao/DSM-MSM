# Source and reuse notice

This local package collects the authors' existing DSM and MSM calculation
implementations for manuscript revision. PROVENANCE.json records their source
locations, source hashes and extracted function hashes.

No distribution license has yet been assigned to the authors' code in this
package. The authors should confirm the copyright holders and select an
appropriate software license before public release. This notice is not a license.

Dedalus, NumPy, SciPy, mpi4py and h5py are external dependencies. Their source
code is not redistributed here, and their own licenses continue to apply.

The repository organization follows practices illustrated by the CPC NNPred
and Xcompact3d MHD articles: separate calculation source, documentation,
examples and checks. No source code from either project has been copied.

Examples consulted:

- Liu, Song and Fang, NNPred (2023): https://doi.org/10.1016/j.cpc.2023.108775
- Fang, Laizet and Skillen, Xcompact3d MHD (2025): https://doi.org/10.1016/j.cpc.2024.109400
